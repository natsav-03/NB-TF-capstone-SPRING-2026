# NB-TF-capstone-SPRING-2026
Analysis script for the 41030 Engineering Capstone report "Transcription factor control of ADRN/MES identity, viability and prognosis in neuroblastoma" (Natalija Savkovic, UTS, 2026).

Data (DepMap cell lines and the Kocak tumour cohort, pre-processed) are not included. Place the files listed in the script header in a folder called data/ and run the script from top to bottom in a fresh R session (R 4.5.2).

This repository is archived and contains the final version of the script submitted with the report (October 2026).
